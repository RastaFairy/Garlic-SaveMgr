# Garlic SaveMgr Python v6.6.1 — legacy snapshot

This directory preserves the Python/PySide6 source that served as the functional reference for the public C# port that reached v6.8 and was maintained in v6.8.1.

It is kept for historical traceability and comparison. The actively maintained client in the repository root is the C#/.NET 8 + WPF implementation under `GarlicSaveMgr/`.
