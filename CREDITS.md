# Créditos y atribuciones

**Garlic SaveMgr** es un proyecto de **RastaFairy**.

Repositorio: https://github.com/RastaFairy/Garlic-SaveMgr

La implementación actual del cliente es C# / .NET 8 / WPF. Este árbol corresponde a la revisión funcional **6.8.7.50**.

## Infraestructura y proyectos relacionados

- `garlic-savemgr` — https://github.com/earthonion/garlic-savemgr
- OpenAGC PS5 Payload SDK — https://github.com/OpenAGC/ps5-payload-sdk
- ps5-payload-dev — https://github.com/ps5-payload-dev

Garlic SaveMgr es el **cliente para PC** y no reclama la autoría de los payloads o proyectos externos.
